# 图框与属性标题栏

用户要加图框、换图签、填写标题栏或调整图幅时读取。本文件的通用模板不是报审标准；优先使用用户正式 DWG/DWT 图框及字段约定。

## 选择与放置

1. 查询目标图纸、当前空间/布局、单位、已有图框、块名及属性。明确是新增、替换还是更新属性；已有图框不重复插入，替换只处理已确认的对象。
2. 明确图幅、横竖向、比例、目标空间和插入位置。尺寸基于纸面毫米。布局中按纸面 1:1 放置，模型保持真实尺寸；比例由视口控制。新建布局先确认页面设置、纸张和打印范围，不把现成布局设置改成模板默认值。
3. 模型单位每单位等于 u 毫米、出图比例为 1:N 时，纸面长度 p 对应模型长度 p*N/u。毫米模型 u=1，米模型 u=1000。例如米模型 1:500，A3 420 mm 对应模型宽 210 m，纸面字高 3.5 mm 对应 1.75 m。布局毫米到米模型的视口“纸面/模型单位”比值为 u/N；先确认接口对比例的定义再设置，不直接照抄 1/N。
4. 属性更新按标签映射，不按位置猜字段。保留原块名、未知属性及其他插入实例；避免重定义全图共用块。通用模板标签为 UNIT/单位、TITLE/图名、NUMBER/图号、SCALE/比例、MATERIAL/材料、DESIGNER/设计、DATE/日期。已有图签若标签不同，显式建立映射。
5. 用实际块/属性查询核对七个标签、中文值、插入点和比例；截图检查字体、越框、遮挡。读取成功不等于纸面排版正确。未填写字段保持空白，不虚构项目、设计人或日期。

## 随附的离线模板生成器

`scripts/cad_templates.py` 只生成独立新 DXF，不连接 CAD，不修改当前 DWG，不覆盖已有文件。需要 ezdxf；可使用已有隔离 Python 环境，缺少时在工作目录创建虚拟环境安装 `ezdxf`，不要使用写死的个人 Python 路径或修改全局环境。

在技能根目录运行（路径根据实际工作目录指定）：

```powershell
python scripts/cad_templates.py --size A3 --fields assets/drawing/title-fields.example.json --out "D:/工作目录/图框_A3.dxf"
python scripts/cad_templates.py --size A4 --portrait --frame-only --out "D:/工作目录/竖向图框_A4.dxf"
```

支持 A0~A4、横竖向。默认横向 A3；图框装订边25 mm，其他边 A0/A1为10 mm，其余为5 mm；标题栏180×56 mm，命名块 `ZW_TITLE_V1`，七个可编辑属性。以上是随附模板尺寸，不代表所有行业适用。示例值只供演示，正式交付前替换。

生成物在 DXF 模型空间按纸面毫米表达。用 `dwg_op` 在独立文档打开，或根据实时 help 使用 `insert_block`/`cross_copy` 导入目标空间；读取实际单位与插入缩放，避免 CAD 自动单位转换和手工缩放叠加。同名块已有不同定义时先改新模板块名或复用已核实定义。

脚本完成结构审计和属性读回；字体使用 `simsun.ttf`，需在目标机器确认可用或替换为已验证字体。最终字体、文字越框、视口和打印效果仍需中望现场检查。DWG 交付通过中望保存，不把 DXF 改扩展名当作转换。
