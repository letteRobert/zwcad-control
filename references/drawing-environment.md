# 绘图环境初始化

新建图纸、建立项目绘图设置或补充样式时读取。配置是执行依据，不是新的桥接接口；JSON 不会自动应用，按实时 help 转成 `sysvar`、`layer_manage`、样式查询或经核实的 Lisp 请求。

## 项目配置

随附 `assets/drawing/new-mm.example.json` 和 `survey-m.example.json`，分别演示毫米新图和米单位测绘模型。复制到工作目录填写，用户图纸/正式模板优先于示例。

关键字段：model_unit、millimeters_per_model_unit、coordinate_system、paper_unit、scale_denominator、paper_text_height_mm、layers、styles。示例不是已确认的苍岭镇项目标准。coordinate_system 为空表示未知，不能据文件名猜坐标系。

## 增量执行

1. 先记录目标 DWG、当前空间、INSUNITS/MEASUREMENT/LUNITS/LUPREC/LTSCALE、当前图层、文字与标注样式及对象范围。只读任务不初始化。单位无定义或设置与实际坐标冲突时，结合已知长度/项目说明确认；不凭坐标大小判米或毫米。
2. 比较“当前值/目标值/处理方式”，只补任务需要的缺失图层或新样式。已有同名样式不同则复用合适样式或用项目后缀新建，不改共用定义。保留已有颜色、锁定/冻结/关闭状态及对象特性；不批量解锁、归层、改 ByLayer 或清理无关对象。
3. 新图可在单位确认后设置 INSUNITS；既有图修改单位标记不等于几何缩放，也不等于坐标转换。单位换算、坐标系转换、移动原点需单独明确输入和目标，不作为初始化附带动作。
4. 模型文字高度 = 纸面字高 * 比例分母 / 每模型单位毫米数。布局文字按纸面毫米。标注使用真实模型测量值；长度显示换算、DIMSCALE、注释性样式分别核对，不重复缩放。比例未定时保留现有设置，不猜字高。
5. 字体先确认目标机器可用。仅在已验证的 SHX 配置中使用大字体；不能把“中文必须 gbcbig.shx”当通用规则。缺字体不静默替换正式图纸样式。
6. 临时改变的 CLAYER、OSMODE、CMDECHO、ATTDIA、ATTREQ 等在正常结束/取消/错误后恢复；新建的项目设置按任务保留。执行后读回变更项，检查一处文字/标注的真实尺寸与外观，记录未应用项。新图另存，现有图按用户指定保存。
